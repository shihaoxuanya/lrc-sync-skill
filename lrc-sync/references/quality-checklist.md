# 发布前验收

## 一首歌的交付

- 实际文件存在，测过真实时长和音频指纹；录音版本不是凭标题推断。
- 原稿全文、顺序、重复次数和分行得到保留，没有把歌名/制作信息当成歌词。
- 无均分时间、凭字数估时、随机插值或把结尾强塞到末尾。
- `null` 不冒充时间，负数、NaN、倒序、相同百分秒和越界会被拒绝。
- 检查开头、转场、重复段、最后一句、实际唱完点、间奏与尾奏清屏。
- 区分声谱/自动对齐候选与实际试听，标明未复核部分；不虚构误差范围。
- LRC、HTML 和项目 JSON 均能打开；UTF-8 中文不乱码；文件名对应音频。
- HTML 默认不内嵌音频；有内嵌时在交付说明提醒，不放到公开仓库。

## Skill 的发布

- SKILL.md 名称与目录名一致，触发范围明确；命令在当前目录结构下可运行。
- Python 单元测试与浏览器冒烟测试通过；如未运行某项，明确说明。
- 用本地合成提示音检查读音频、选择行、微调、撤销、保存恢复和下载。
- 特殊文本如 `</script>` 被当成数据显示，不会执行代码。
- 打包清单逐个检查，不含个人音频、完整商业歌词、含音频的 HTML、截图、密钥、绝对个人路径或工作缓存。
- GitHub 变更只触及已授权目标，保留其他项目主分支和文件。
- 若连接不支持创建仓库，不把“已上传到分支”说成“已经新建独立仓库”。
